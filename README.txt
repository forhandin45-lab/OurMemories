RUANG KENANGAN - VERSI AWAL

Kata sandi awal: kenangan
Untuk mengganti kata sandi: buka app.js, ubah const PASSWORD="kenangan".

Fitur:
- Login kata sandi
- Sajak langsung di halaman utama
- Sajak otomatis paling baru di atas berdasarkan tanggal dibuat
- Edit/hapus satu sajak
- Foto/video lokal untuk pengujian awal
- Kalender umum: haid, jadwal ketemu, ulang tahun, anniversary, tanggal penting, lainnya
- Klik tanggal untuk langsung membuat catatan
- Edit/hapus satu catatan kalender
- Tidak ada hapus semua

Tahap berikutnya: sambungkan galeri ke Supabase agar foto/video dapat disimpan online.
